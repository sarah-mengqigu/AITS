# Optional AI stack: LangGraph orchestration + LangChain glue layer.
#
# The platform runs fully without this file:
#   * orchestration falls back to the built-in StateGraph implementation
#   * agents fall back to the project's thin LLM client / prompt builder /
#     JSON parser / cosine RAG / offline MCP tool index
#
# Install with:
#     backend/.venv/bin/pip install -r backend/requirements-ai.txt
#
# Engine switches (see backend/.env.example):
#     AITS_AGENT_ENGINE=auto|builtin|langgraph
#     AITS_LLM_BACKEND=auto|langchain|http
#
# Measured footprint on macOS arm64 / Python 3.10.9:
#   * download ~19 MB, installed ~+102 MB (venv 165 MB -> 262 MB)
#   * backend RSS +26 MB at import (LangChain glue), +80 MB when the OpenAI
#     SDK / vector store are actually used
